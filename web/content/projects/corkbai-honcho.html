The Plain Facts, Carved

What It Is

ᚑ

A shared memory culture for the agent fleet, running on cork: the common ground the garden’s intelligences drink from. One Honcho-backed store of sessions, insights, and documents — kept in the house rather than rented — that every agent in the fleet reads and writes.

The idea is the old one: minds kept in the same household come to know the same things, without needing to be the same mind. A fleet with a shared memory answers in chorus what a fleet of strangers answers in fragments.

It exists because memory that lives elsewhere is memory someone else is holding, and the garden keeps its own — on cork, self-hosted, always on.

Told in the Seanchaí Tradition

The Build Story

ᚏ

Every household in the old stories had a common — the shared thing, the pot or the well or the field that no one owned separately and everyone drew from, and the tradition is unanimous about the rule: the common is held, not rented. Whatever the house draws its life from, the house must keep, because a well that belongs to someone else is a well that can be moved. And the stories of the sídhe have a sharper version of it: the otherworld’s cauldron — the one that feeds everyone and never empties, the one every quest in the old tales is secretly about — is never carried off by force, only ever inherited by the household that keeps it warm. This keeper is the garden’s cauldron: corkbai-honcho, the shared memory the whole agent fleet draws from — every session logged, every insight kept, every document in the one pot on the one hill where the household can reach it, on cork, in the house, held not rented. The minds that drink from the same pot, the tradition says, come to tell the same stories — and a house that tells the same stories is one house. The moss grows on this stone like the green on a common hill: evenly, and by right.
