The Plain Facts, Carved

What It Is

ᚔ
First steps with Docker and Python — a beginner's repository for learning how to containerize Python code: writing a Dockerfile, building an image, and running the result. The exercises are small on purpose — the classic containerized Python workload, built and rebuilt until each step of the pipeline (image, container, volume, port) was understood by hand rather than by copying incantations from the internet. It exists as the garden's first flagstone in container craft, laid in 2024: everything heavier that ships from here since rests on knowing exactly what this small stone proved.

The Build Story

ᚏ

The first flagstone of Newgrange was laid without knowing the roof would still hold five thousand winters on — the masons set it down because a doorway has to start somewhere, and the great corbelled dark above it was still only a rumor in the mind. The Norse knew the same laying-down in their way: the knarr was built small and true before any cargo trusted it, and a hull that holds in the harbor is worth more than a saga of ones that did not. So this stone was laid: one container, one Python tongue inside it, sealed with a single written rune that says build me thus. The seal was tested at the water's edge, so to speak — the image built, the container ran, the little program spoke from inside its walls. It is the smallest of the garden's foundations and the most leaned-upon since, and the moss grows along its seam where the harbor-light falls.
